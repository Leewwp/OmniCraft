# 媒体体验范式：contain + 桌面双栏 + 移动端连续浏览

2026-08-08 接受此决策：内容详情与浮层的媒体区以 contain 不裁切 + 几何稳定为默认范式（超高图限高滚动），点击媒体区进入全屏媒体查看器（缩放/翻页/外部点击+Esc+按钮退出）；桌面端详情浮层改为左媒体右信息双栏，移动端保持全屏单列；移动端沿触发上下文列表上滑逐篇连续浏览，桌面/web 端不做自动加载下一篇，改为正文后展示相关内容块并提示「已经到底了」。列表卡片按媒体集首项/poster 自然比例渲染，封面派生（图片 = 首图，视频 = 首帧或自定义 poster），上传时采集宽高并反范式化到 `content_items` 封面宽高列。虽然裁切填满（fill）与统一卡片比例更省事，且小红书式「自动加载下一篇」看似更沉浸，但 contain + 稳定几何避免竖图被剪与布局跳版、双栏让竖图获得全视口高度、相关内容块避免桌面端被无限续播裹挟——这些取舍以 2026-08-08 用户确认的 14 项决策为准，详见 `docs/superpowers/specs/2026-08-08-omnicraft-media-experience-design.md`。
