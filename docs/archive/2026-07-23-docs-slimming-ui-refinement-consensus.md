## 六、UI 精致化（需求二，Q13-Q15）

- **Q13 审美方向：精致极简**。保留扁平骨架 + Indigo 主色；补工艺层：三级极浅阴影/海拔、字阶与间距节奏、边框色阶、真封面卡片 + 悬浮微交互、精致空态/加载态、品牌色克制点缀。参考 Linear / Vercel / Notion；卡片流保留小红书式。确诊病灶：灰占位盒泛滥、零层次、空态潦草、品牌色缺席。
- **Q14 过程：正确性修复后原型先行**。先完成不决定视觉方向的 U-05/U-02A/U-04 → 样板页完整重设计 → 截图评审迭代到用户明确批准 → 令牌/组件回写 design-system.md 与 ui-spec.md（U-01/U-02B）→ 导航壳层与页面清单分批推广（light 车道）。
- **Q15 样板页**：首页 feed + 内容详情页；桌面 + 移动 + 暗色模式全部覆盖。
