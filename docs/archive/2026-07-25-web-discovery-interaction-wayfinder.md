# Web 发现与互动体验 Wayfinder 地图

**创建日期**: 2026-07-25

**预计失效日期**: 2026-09-25

**状态**: 进行中（GitHub CLI 不可用，使用本地 Markdown 追踪）

## Destination

形成一份经用户批准的 Web 发现与互动跨端设计包：包含四项顶部导航、推荐流、内容详情浮层、作者互动、用户资料浮层和 Agent 工作台的明确边界，并包含后端能力契约、数据口径、安全边界与分阶段实施计划。设计确认后再进入生产实现。

## Notes

- 领域词汇见根目录 [CONTEXT.md](../../CONTEXT.md)。
- 视觉审批仍受 P-01 约束；未获批准前不得回写生产 Token、共享组件或导航壳层。
- 推荐流采用多目标排序；Agent 普通写操作需要逐项确认，敏感账号操作不开放。
- 所有站内内容卡片入口（推荐流、分区页、IP 详情页、Agent 引用卡片、浮层内关联区块）进入内容详情时统一使用内容详情浮层；完整详情页仅服务直达链接。

## Decisions so far

- **2026-07-28 A2 范围收窄（最新）**：用户确认生产二创页 `/`、原创页 `/original` 与 IP 详情 `/ip/[ipId]` 的现有 UI 可直接沿用，不再为它们构建 throwaway 原型。A2 只构建新的 IP 库原型，解决 `/ips` 固定 156px 卡片置于五个弹性 Grid 轨道后在 1280px 视口产生约 90.6px 卡间空白的问题；生产实现仍在 P-01 批准后由 U-09 承接。
- **2026-07-28 范围修订（历史；A2 表面清单已由上条收窄）**：用户对当前 Indigo 原型较满意，取消 Hallmark Tally 方案 B，不再生成第二方向或将其作为 P-01 批准前置条件。当前 Indigo 方向成为唯一后续基线；开始 A2 时一并移除误导性的 B 切换入口与 B 专属重复截图矩阵。
- **2026-07-28 二次修订（A1.6 细节交互访谈）**：在 A1.5 与 A2 之间插入 A1.6，细化创作者栏/资料浮层、评论自增高与 2000 字限制、中性关系状态、桌面居中私信，以及 Agent 侧栏顺序和跨全部保留会话的全文搜索。P-01 仅使用完整 mock 数据；真实 owner-scoped 全历史搜索仍由 Web Agent Productization 承接。
- **2026-07-28 修订（A1 后续调整访谈）**：在 A2 前插入 A1.5 共享交互修订，用户资料浮层与私信聊天浮层从“后续轮次”提升到当前 P-01；新增评论/私信单图 mock、Agent 会话侧栏搜索/折叠、最短列瀑布流、统一浮层动画和唯一内部滚动模型。真实图片附件、OSS 与内容安全接线明确留给后续 heavy 任务。
- **2026-07-27 修订（用户评审原型2 后确认）**：方向 B 由 Newsprint/编辑策展改为 Hallmark 官方 Tally 示例（SaaS · modern-minimal）路线；浮层从「推荐/Agent 专用、单层」改为「全内容入口统一、带逐层返回导航栈」；首轮表面由五个扩展为八个（新增二创分区页、原创分区页、IP 库、IP 详情页）；完整详情页降级为仅服务直达链接。该日原定 A1 → A2 → B，后由 2026-07-28 决策插入 A1.5；以下条目以最新修订为准。

- 首轮原型的第一受众是已登录的内容探索者／轻度创作者：他们熟悉社区基本操作，主要发现原创与二创内容，并使用 Agent 查找、理解和延伸站内内容；活跃内容创作者作为第二受众。
- 首轮原型的单一核心任务是完成一次上下文保留的内容发现闭环：用户从推荐流或 Agent 回答发现内容，打开共享内容详情浮层完成理解，再关闭浮层并无损返回原浏览或对话位置。发布、关注、私信和 Agent 写操作不是本轮首要成功标准。
- Hallmark Tally 方向 B 已取消；2026-07-27 的 Tally 路线仅保留为历史决策记录，不再构造对应 token、组件、页面或截图矩阵。
- 顶部导航采用推荐、二创、原创、AI Agent 四项。
- 顶部全站搜索与 Agent 工作台分工：搜索负责关键词发现，Agent 负责会话式检索与受控协助。
- Agent 工作台采用顶部导航进入的独立全页受保护路由 `/agent`；不保留 Root Layout 全站右下角 Agent 浮动入口。仓库默认 feature flag 继续关闭，现有全局挂载仅作为未来迁移输入。
- 内容详情浮层承载与完整详情页一致的完整内容（含评论区、相关推荐、关联原创/二创、所属 IP）；标题下方不重复作者信息，右侧创作者栏以同一行展示头像、可省略昵称与固定约 80×32px、无额外外框的关注按钮。浮层内访问关联内容形成逐层返回导航栈：返回类手势（返回按钮、Esc、浏览器后退）逐层弹出，退出类手势（显式关闭、背板点击）退出整个浮层；返回文案只显示来源或上一条内容标题，不显示层数或解释文本。
- 从 Agent 引用卡片关闭内容详情浮层后，恢复原会话滚动位置并把焦点返回引用卡片；所有入口采用同一恢复契约：完全退出浮层后恢复最初的触发入口、滚动位置和焦点。
- 内容详情浮层打开时锁定 html 与 body；dialog/外壳不滚动且不保留外部滚动条，只有内部内容主体滚动，顶部返回/关闭栏固定在其外。每层只记忆这一滚动容器，彻底消除双重滚动上下文。
- 内容浮层开合由弹窗外壳和封面共享同一动画进度：开 300ms、关 240ms、同帧开始/结束；Agent 引用入口复用，缺缩略图/触发卡不在视口时降级为居中轻缩放+淡化；reduced-motion 为 100ms 纯淡化。
- 用户资料浮层覆盖创作者主页以外所有用户头像/昵称入口；桌面悬停显示/关闭均 200ms，键盘聚焦立即显示，移动端点击直接进入用户主页。内容详情右侧创作者栏的资料浮层优先在触发项下方居中、空间不足时上翻并限制在详情可视区；评论发布者继续既有动态定位。内容发布、累计获赞、关注者采用当前公开未删除内容口径并导航到主页相应公开视图，不展示点赞用户名单；未填简介直接省略。
- 未关注使用蓝底白字“关注”；已关注与取消关注使用浅灰背景和深色文字/图标且不使用红色，此中性选中/取消态同步到收藏、订阅。资料浮层中的“私信”在当前上下文上方打开私信聊天浮层，不跳转消息中心；查看自己时只显示“编辑资料”。
- 私信聊天浮层是简化完整会话：昵称头与编辑器固定、中间历史单独滚动，桌面约 440px/最高 70–75dvh 并默认在当前视口居中、不跟随资料浮层定位，移动全屏；关闭只退最上层并恢复下层位置/焦点。冷启动（接收方未关注发送方且未回复）只允许一条纯文本，关注或回复后永久解锁图片和后续消息。
- 私信每条最多一张 JPEG/PNG/GIF/WebP 图片且 ≤10MB；顶层评论和回复每条最多一张同格式图片且 ≤5MB，均允许纯图片。选图后立即校验/临时上传，成功前不可发送，失败保留草稿并安全提示。
- 图片采用发送者乐观可见、接收方先审后显：审核中发送者侧无状态，通过后静默正式可见，失败仅在图片侧显示红色感叹号；文字+图片为原子消息/评论，图片失败则整条不投递。点击已发送图片进入独立预览层，最上层优先关闭。
- 顶层评论和楼中楼回复共用一行起始、最多六行后内部滚动的编辑器，文本上限 2000 字；聚焦时显示计数，超长粘贴截断，失焦隐藏计数/友善提示/图片入口/发布按钮但不清空文字或附件；不使用边框加粗或缩放表达鼠标聚焦，保留键盘 focus-visible。
- Agent 工作台桌面端为固定视口应用式布局，页面外壳与主列不滚动，仅对话正文区域滚动；展开侧栏从上到下为带文字的折叠按钮、搜索触发框、全宽新对话、历史，收起为 56–64px 持久化窄栏并保留展开/搜索/新对话三图标及 Tooltip，移动端折叠即关闭抽屉。搜索覆盖当前账号全部未删除会话标题与消息正文，不受侧栏加载范围限制；每条命中独立列出并按时间倒序，显示会话来源、片段和日期，点击定位具体消息并短暂浅灰高亮。桌面使用 `min(720px,92vw)`/最高 80dvh 居中层，移动全屏；支持 `Ctrl/Cmd+K`、Esc、方向键/Enter、焦点恢复；无结果状态仅保留输入框右侧清空入口。
- 推荐流、原创分区和 IP 详情的可变高卡片按返回顺序逐条放入当前最短列，保持 DOM/键盘/读屏顺序；固定比例二创卡与 IP 库卡继续规则网格。
- P-01 证据包由已完成的推荐流、Agent、内容详情浮层/直达详情隔离原型，加上现有生产二创页、原创页、IP 详情视觉基线和新的 IP 库隔离原型组成。现有三个生产页面不复制到 throwaway 原型；共享详情浮层仍是产品级契约，但这些生产页面的接线不再是 A2 原型验收项。
- 首轮只保留当前 OmniCraft Indigo 设计体系的单一视觉方向；A1.5/A1.6 的资料、私信、评论、Agent 与瀑布流契约继续作为 A2 复用基线。
- 原型按四批开发和评审：A1 修复与合并（已完成）→ A1.5 共享交互修订（已完成）→ A1.6 细节交互修订（已完成并验证）→ A2 IP 库原型。完成 IP 库的响应式、明暗色、状态与进入现有 IP 详情的验证后，再请求 P-01 最终批准。
