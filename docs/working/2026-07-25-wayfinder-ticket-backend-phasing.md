# 决策票据：后端能力分期与前端原型门

**创建日期**: 2026-07-25

**预计失效日期**: 2026-09-25

**状态**: open

## Question

哪些后端能力契约可以与隔离前端原型并行设计，哪些必须等 P-01 视觉批准后进入生产实现；如何避免原型试错导致数据库、路由或组件提前锁定？

## Resolved documentation boundary on 2026-07-26

- 独立 `/agent` 工作台、Root Layout 全局挂件移除、keyword-only 全站搜索和共享内容详情浮层已经同步到领域、架构、业务规则、UI 规格与活跃计划。
- P-01 阶段仍只允许隔离静态原型；不得创建生产 `/agent` 路由、移除生产 `AgentChatWidget`、重命名搜索组件或修改 feature flag。
- 生产迁移由 `docs/superpowers/plans/2026-07-16-omnicraft-web-agent-productization.md` 和 P-01 后续 UI 任务按依赖执行；真实 Provider 缺失仍按阻塞处理。

## Resolved documentation boundary on 2026-07-28

- P-01 A1.5 只为用户资料浮层、私信聊天浮层、图片私信和图片评论提供静态交互 mock；不得在 light 车道新增消息/评论附件迁移、OSS 上传接口或内容审核接线。
- 真实图片私信与图片评论必须登记为后续 heavy 工作：TDD 开始，迁移/附件所有权审查，按用途签发并一次性消费上传授权，JPEG/PNG/GIF/WebP 扩展名+MIME+文件签名校验，私信单图 ≤10MB、评论/回复单图 ≤5MB，临时对象清理，阿里云图片先审后显及发送者私有失败状态。
- 冷启动生产规则由“对方回复后解锁”修订为“接收方关注发送方或回复后解锁”；当前后端仍为旧规则，属于已记录的代码/设计漂移，不在本次文档任务中修改。
- P-01 A1.6 仅用完整 mock 会话集验证 Agent 会话全文搜索；生产端不得退化为客户端过滤已加载标题。真实能力必须 owner-scoped 搜索当前账号全部未删除会话标题与消息正文，每条命中独立返回并按时间倒序，支持分页与精确消息定位，且不消耗 Provider 生成配额。
- 生产全文搜索由 `docs/superpowers/plans/2026-07-16-omnicraft-web-agent-productization.md` 承接；具体 API、游标和索引方案在实施前于本票据收敛，如涉及索引/迁移则按 heavy 车道执行。
- P-01 批准只代表交互与视觉获批，不代表上述生产能力已实现或可发布。
